## 5. 光学校准记录

必须分开记录源稿归一化与归一化后的微调，不只写一个总translation。

| 字段 | 内容 |
| --- | --- |
| geometryNormalization | 原稿到规范坐标的缩放／平移／重绘说明 |
| opticalCorrection | 归一化后最终微调的dx、dy，单位u |
| 候选版本 | 零微调及邻近候选，说明为什么选最终版本 |
| 实际应用位置 | 已烘焙几何／库内平移组；不能同时重复应用 |
| bbox辅助数据 | 校准前后均记录；仅为诊断 |
| 墨量重心辅助数据 | 可选；不能作为唯一通过条件 |
| 大幅偏移复审 | 任一轴微调超过0.5u时填写理由与结论 |
| 对照基准 | 用了哪些已批准字形混排 |
| 原尺寸比较证据 | 16／20／24及实际追加尺寸的路径 |
| 无辅助线观察结论 |  |
| 真实容器观察结论 |  |
| 成对状态／方向比较 | 适用时填写主体与共用基线是否稳定 |
