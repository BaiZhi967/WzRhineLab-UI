## 3. 反向验证
逐项破坏实现、确认对应测试失败、再恢复（脚本化执行，源码恢复后 diffstat 不变）：

| 破坏 | 拦住的测试 |
| --- | --- |
| 边界禁用时不回退焦点到当前页 | Pagination「pressed control becomes disabled at an edge」 |
| 再次加载时清空旧行 | DataTable「reload keeps the old rows」 |
| 不统计其他页的选中 | DataTable「selection survives paging」 |
| Meter 不在 `aria-valuetext` 中带状态文字 | Meter「threshold state is spoken」 |
| 当前页按钮设为 disabled | Pagination「current page is marked and stays focusable」 |
| DataTable 加载时把分页设为 `disabled` 而非 `busy` | DataTable「paging is inert but stays focusable」 |
| 传入的 `aria-label` 被默认文案覆盖 | Pagination「explicit aria-label names the landmark」 |

此外，面包屑「单行、不重叠」和分页「320px 不换行」都在 E2E 中按几何关系断言。

截图位于 `apps/docs/test-results/screens/`（未入库）。新页面五种宽度浅色整页、1280 错误态明暗、档案页与验收场景页（RecordHeader 路径）。首轮问题与修复见第 2 节，复审结果：

| 轮次 | 范围 | 结果 |
| --- | --- | --- |
| 1 | 36 张切片 | 7 张不通过：面包屑换行与提前截断、320px 分页标签折行、表格错误信息左对齐（见第 2 节） |
| 2 | 45 张切片（含档案页、场景页） | 分页与错误态通过；档案页与场景页的 RecordHeader 路径正常。**面包屑仍不通过**：祖先项被压缩成零宽或残缺字形（如「衤」「⺇」），分隔符挤在一起，320 / 390 根项消失，宽卡片上最后一项仍提前截断 |
| 3 | 面包屑近景 12 张（5 种宽度 × 折叠 / 展开，加两张 RecordHeader 路径） | ✅ 12 / 12 通过 |

第 2 轮问题的修复：不超过 4 个字的祖先项不压缩；更长的祖先项最多压缩到「3 个字 + …」，最小宽度按文字逐项计算（不会大于标签本身，因此不会在短标签后留出空白）；最后一项只在行满时截断。放不下时整条路径在自身框内横向滚动。responsive E2E 的溢出检查因此把 `.rl-breadcrumb` 列为有意的内部滚动容器（与表格、代码块相同）。

E2E 新增几何断言：5 种宽度下单行、不重叠；被截断的祖先项宽度不少于 3 个字；最后一项出现省略号时，行末剩余空间不超过 2px；390px 以上折叠路径不滚动。

复审遗留（不影响判定）：1280 宽度下最后一项在全角括号后截断（「流程（…」），读起来略别扭，属于浏览器按字符截断的正常结果。

## 5. 设计决策与偏离
- **Pagination `busy`**：ADR-0005 原定加载时「禁用」分页，实测会丢焦点，因此改为 `aria-disabled` + 忽略点击，ADR 已同步修订。
- **面包屑按项数折叠，不按宽度折叠**：未折叠的长路径在窄屏上于自身框内横向滚动，不撑宽页面。按宽度自动折叠需要测量与 ResizeObserver，留作后续评估。
- **面包屑压缩下限按文字计算**：每个长祖先项的最小宽度由前 3 个字估算（CJK 1em、拉丁等宽 0.6em，加字距），写入行内 CSS 变量。非文本标签（ReactNode）不压缩。
- **路径 DOM 变化**：RecordHeader 路径多了 `rl-breadcrumb*` 类（外观与语义不变）。ssr-hydrate 的断言因此调整，并已写入 CHANGELOG 迁移说明。

## 6. 未覆盖与遗留
- 不分页一次渲染 1000 行的性能；DataTable 仍没有虚拟滚动。
- 读屏软件（NVDA / VoiceOver）、200% 缩放、真机触控仍未人工验收；键盘路径只有自动化测试，**没有人工键盘验收记录**。
- 视觉基线只覆盖 Chromium on Windows。
- Firefox 进程在并行运行示例时偶发崩溃（浏览器侧问题，重跑通过）。
- WebKit 全量运行后进程不退出（既有问题，结果需从 JSON reporter 读取）。
- 默认文案为中文，可逐项覆盖；locale 方案见 M9.5。
