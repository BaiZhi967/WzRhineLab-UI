# 验收记录 · M12 — Advanced interaction + Agent UI

- 分支：`feat/m12-agent-ui`（基于 `main` 15cfcfc：M0–M10、M9.5 与 Agent 概念图册导入）
- 环境：Windows 11 · Node 24 · pnpm 10.17.1 · Playwright 1.63.0（Chromium / Firefox / WebKit）· Base UI 1.9.0 · React 19.3
- 维护者决定：跳过 M11 Rendering Lab（保留 Planned）；M12 同时交付高级交互组件与 Agent UI；允许对 agent 包做更细的拆分；依赖后续路线的内容可以提前开发。
- 契约：[ADR-0010](../adr/0010-m12-agent-ui-plan.md)（范围、拆包、顺序）、[ADR-0011](../adr/0011-agent-contracts.md)（view-model、状态轴、action、renderer、文案）、[ADR-0012](../adr/0012-agent-motion.md)（Agent 动效）
- 参考：Agent 概念图册（`docs/concepts/agent`，46 个组件，只作提案）与 Wpi-Agent `packages/agent-ui`（只参考行为与覆盖面，未复制代码与视觉）。
- 只列真实执行过的命令；未执行项单独列出。

## 0. 开发方式
1. 协调者先完成基座并提交：`@wzrhine/agent-core` 全部契约与纯函数（含单测）、`@wzrhine/agent` 的文案表框架、图标、`StatusGlyph` / `AgentStatus` / `AgentSpark`、动效层、fixture、边界测试；react `Collapsible`；三份 ADR；Showcase 路由骨架。
2. 八个子任务并行：六个 Agent 组件族（Shell、Message、Tools、Composer、Intervention、Workspace），以及两组 react 高级组件。每个子任务按共享说明只改自己的文件，并交付组件、样式、中英文案、单测、Showcase 页、E2E 与组件文档。两个子任务中途停止，由新的子任务接续完成。
3. 协调者集成：Agent 集成工作台（示例 adapter 驱动全族）、动效页、release 脚本接入两个新包。
4. 对照 Wpi-Agent 做缺口分析（子任务只读审计 64 项能力），把通用、可视图化的缺口补进契约，再由三个子任务并行实现；另一个子任务新建示例应用 `agent-console`。
5. 统一复验：`release:check`、三内核 E2E、示例、视觉基线与视觉评审。

## 1. 交付范围
### 1.1 `@wzrhine/react`（+10 个组件）
Collapsible、Accordion / AccordionItem、Slider、NumberField、ContextMenu（第一组）；Combobox、CommandPalette（含异步模式）、FileDropZone（第二组）；SplitButton、ScrollArea（Wpi 缺口）。新样式分片 `disclosure.css`、`advanced.css`、`command.css`、`split.css`；新增文案命名空间 numberField、combobox、commandPalette、fileDropZone 等。FilterBar、DatePicker 仍为 Planned。

### 1.2 `@wzrhine/agent-core`（新包）
- 状态轴：`RunStatus`（9）、`RunPhase`（13）、`SyncStatus`、`ActionStatus`、`ToolStatus`（12）、`TerminalSessionStatus`、`SubagentStatus`、`DraftStatus`、`Completeness`。全部为 kebab-case，图册中的 snake_case 与 `awaiting-approval` 不再使用。
- view-model：会话、消息（13 种 part）、运行 / 过程、工具（11 种专项 detail）、审批、问卷、授权、Composer、终端、子任务、上下文用量与统计、摘要、账本、文件预览、运行摘要与详情、技能使用、分页材料。
- 纯函数：
  - 合并与守卫：`mergeById`（旧 revision 不回退，不产生重复 id）、`sequenceGaps`、`buildTree`；
  - 状态元数据：字形与色调；
  - composer token：编码、吸附、整体删除、触发识别；
  - diff：`lineDiff`、`parseUnifiedDiff`；
  - 格式化：`usagePercent` 遇到不完整数据时不返回百分比。

### 1.3 `@wzrhine/agent`（新包）
图册 46 个组件全部有对应实现，覆盖表见 Showcase `/#/agent`，E2E 断言表格为 46 行。对照 Wpi 补齐：

| 族 | 补齐 |
| --- | --- |
| 消息 | RunDetails、SkillUseList、MessageActions 的能力禁用原因与「重新编辑本轮输入」、MessageList `holdFollow` |
| 工具 | ChunkPager（分页材料） |
| 产物 | FilePreviewTabs（多标签）；FilePreview 的打开方式菜单、缩放、面包屑、随时重新读取 |
| 工作区 | ContextUsage 统计与悬停打开；终端调用记录与「有新输出」提示；CompactionNotice 的 interrupted 状态与阶段 / 重试提示；ArtifactList `truncated`；继承的子任务快照 |
| 人工干预 | GrantList（会话信任与额外目录授权）；问卷「放弃未保存填写」 |
| Composer | ComposerNotice / `replacement`（子任务只读） |

Agent 动效（ADR-0012）：
- 首次出现才入场（message / row / card），同批错峰 24ms，封顶 120ms；
- 折叠统一走 Collapsible 的高度过渡；
- Send ↔ Stop 两枚图标交叉淡入；
- AgentSpark 点阵按阶段有不同节奏与静态帧，运行中状态点呼吸；
- 循环只在页面可见、元素在视口内且非减动时运行；
- 不用 spring，不用文字扫光。

### 1.4 应用与示例
- Showcase 新增 10 页：高级交互 2 页；Agent 8 页，包括集成工作台与动效四通道页。
- 新示例 `examples/agent-console`（端口 4178）：
  - 消费者 adapter 把 snake_case 状态映射为 kebab-case；
  - 处理重复、乱序和旧 revision 的事件；
  - 未知回执用同一 actionId 重试；
  - 支持中英切换；
  - 同页两个实例互不影响。

### 1.5 留在应用侧（不进组件库）
以下归宿主或 adapter，符合 ADR-0010 §4 与平台规划 §2.2：
- 窗口与桌面：Tauri 标题栏 / 窗口按钮、关闭保护；
- 设置与数据：设置中心（模型、MCP、技能）、会话环境与自定义指令；
- adapter 逻辑：空会话惰性删除、草稿防抖与 flush、未读跟踪、打开方式探测、目录选择器。

## 4. 修复的缺陷
- **ContextMenu**（库）：Firefox 下 Shift+F10 打不开。改为在触发元素上显式处理 Shift+F10 / ContextMenu 键。
- **CommandPalette 受控用例**（测试竞态）：先等待焦点进入输入框，再按 Enter。
- **responsive 截图**（测试脚本）：超过 32767px 时回落为视口截图。
- 子任务自测阶段修复的问题：
  - 审批 diff 行号在暗色下对比度不足，改用 `--rl-fg-muted`；
  - Composer 镜像层的 mention 高亮缝隙，以及输入框无法缩回；
  - 工作区页长代码行与终端行在窄屏的换行；
  - Firefox 下 FilePreviewTabs 的关闭按钮违反 axe 的 tablist 规则，按钮移出 tablist。

## 5. 未覆盖 / 遗留风险
- **Wpi-Agent 真实接入与双层验收**：平台规划 §10 的完成定义要求「至少一套真实 Wpi 消费页面」，因此 Agent UI 平台**不能**宣称完成。接入指南已给出组件映射与状态名映射，需要在 Wpi 仓库内进行。
- **人工验收未做**：真实中文输入法、读屏（NVDA / VoiceOver）对流式状态的播报、200% 缩放、真机触屏（ContextMenu 长按、侧栏拖动）、Windows 高对比度目视检查。
- `agentEnUS` 与 react 新命名空间的英文文案未经母语审校。
- 视觉基线只在 Windows Chromium 上建立；Agent 页面只截视口。
- 未实现的项：
  - 主对话 ↔ 子任务视图横移动画（ADR-0012 节奏表中列出，`AgentShell` 尚无 `transition` 属性）；
  - 会话索引列拖动调宽；
  - ReferencePicker（独立的文件浏览选择器）、RunOverview（摘要卡 ↔ 胶囊）、SkillPicker 工具栏多选上限。它们在缺口分析中列为 P3，可以由 Composer 插槽与 `CommandPalette` 组合实现。
- 体积：react-full 预算由 153 KB 调为 202 KB（gzip），只在全部组件同时导入时出现，按需导入不受影响。
- WebKit 在 Windows 上仍有退出挂起（M9.5 起的已知问题），需要分段运行。
