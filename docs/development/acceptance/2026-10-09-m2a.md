## 1. 范围
ROADMAP M2 顺序为 Tabs → Tooltip → Dialog → Select → Popover → Toast，本批完成前四个，外加统一的 Provider：
- `RhineProvider`：`.rl-theme` 作用域、作用域内的弹层挂载点、motion/react 减动策略、Tooltip 共享延迟。ADR-0001 约束 2「Portal 必须在主题内」由此在库层面解决。
- `Tabs` / `TabList` / `Tab` / `TabPanel`：line 与 segmented 两种样式，指示器可中断，溢出时有渐隐提示。
- `Tooltip`：仅作视觉标签，触发器须自带名称。
- `Dialog` / `DialogClose`：从 ADR 验证原型升级，支持受控/非受控与退出动画，提供 `onClosed`。
- `Select`：支持分组、表单提交，可接入 Field。
- Showcase：四个新页面与 Playground；全站改用 `RhineProvider`；删除 ADR Lab 原型页及其临时 portal。
- Tokens：对话框宽度、Tooltip 最大宽度、下拉最大高度、浮层间距、z-index 层级。

**未包含（M2-B）**：Popover、Toast，以及 Menu。

## 3. 发现并修复的问题
1. **320px 页面横向溢出 4px**：Tooltip 页截断示例中，按钮内容区没有 `max-width`，长标题撑出容器。修复：`.rl-button__content` / `__label` 加 `max-width: 100%`，`Text truncate` 改为 `display: block`。
2. **Tabs 溢出被误判为页面溢出**：可横向滚动的 Tab 列表是有意设计。修复：测试把 `.rl-tabs__list` 列为内部滚动容器；另断言 `scrollWidth > clientWidth` 且页面本身无溢出。
3. **测试顺序依赖**：同一个测试里依次跑明、暗两种主题时，第二次 `addInitScript` 被首次设置覆盖。修复：拆成两个独立测试。
4. **禁用 Tab 的键盘行为**：Base UI 让禁用的 Tab 仍可用方向键聚焦（`aria-disabled`，不能激活），符合 WAI-ARIA Tabs 模式。单测已改为断言此行为，不强行跳过。

## 4. 视觉审查
首轮问题与处理：
- 390px 下 Playground 里的 JSX 代码在字符中间被截断 → 代码块改为 `pre-wrap` 自动换行。
- Tab 列表溢出在截图里看起来像被裁坏 → 新增末端渐隐，滚动到尾端后消失。
- 短演示卡片被相邻卡片拉高，留下空白 → 改为顶部对齐。
- 1920px 下 Playground 内容过于分散 → 演示区最大宽度限制为 720px。
- 评审认为 Tooltip 触发器的蓝色焦点环「不在色板内」→ **未修改**。它是 `--rl-focus` token（#1F5AA8），ADR-0003 依据 STYLE.md「焦点色不能复用品牌橙」做出的有意决定；橙色焦点环在 Accent 按钮上也会看不见。
