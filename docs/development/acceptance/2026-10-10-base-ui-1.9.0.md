## 3. `test:examples:all` 合跑的既有 flake（与本次升级无关）
- 现象：`pnpm test:examples:all`（archive-desk 三内核合跑）稳定失败 3–4 项（`locator.click` / `toBeVisible` 超时，30s 上限），单测试耗时 16–27s、逼近上限；改为逐内核顺序执行则全部通过。
- **对照实验**：另建基于同一 `main`（Base UI 1.8.0）的对照 worktree，相同端口补丁、相同命令合跑，同样失败（两次分别 3 项、4 项，失败数本身漂移）——证明是并行负载下的既有超时问题，非 1.9.0 回归。对照 worktree 已删除。
- M6 验收记录中示例亦按内核分批执行，与此结论一致。
- 建议（未实施，避免混入升级 PR）：提高示例测试 timeout 或在 `test:examples:all` 里按内核分批调用。
