## 3. Spike 发现
1. **jsdom 无法验证 Tab 循环**：Base UI 用 focus guard 重定向焦点，jsdom 不执行，Tab 会落到 `<body>`。真实 Chromium 中 8 次 Tab/Shift+Tab 均在弹窗内（已断言）。jsdom 套件只断言首个 Tab 停在弹窗内。
2. **valueMissing 降噪**：Base UI 只在值被修改过之后才报告必填缺失；提交时仍会校验。已写入组件文档，测试按此行为编写。
3. **Portal 必须挂在 `.rl-theme` 内**：默认 Portal 到 `<body>` 会丢失主题 tokens 与减动属性。Showcase 增加主题根内的 portal 容器，暗色下弹窗底色已断言为 `--rl-bg-raised`。ADR-0001 将此列为使用约束，M2 由库提供统一 Provider。

## 4. 视觉审查
首轮问题：Field 页「States」卡片被相邻的长表单拉高，中间约 240px 空白。修复：表单改为整行两列，States / Adornments / Inline 改为等宽三列；生成的 JSX 每个属性独占一行（390px 不再截断）；768px Playground 控件顶对齐；缩短脚注避免两字孤行。
