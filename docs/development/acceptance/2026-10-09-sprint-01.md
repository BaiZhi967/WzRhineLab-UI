## 3. 发现并修复的问题
1. Button 与 motion 事件类型冲突 → 从公共 Props 中排除 6 个冲突事件。
2. `@wzrhine/react` 入口带 CSS 副作用 → 移除，改为显式样式导入（ADR-0002）。
3. Showcase 全局重置（`.sc-app button { color: inherit }`）特异性高于 `.rl-button`，深色 Accent 按钮文字被覆盖为浅色（axe 2.12:1）→ 重置包进 `:where()`，特异性归零。
4. 浅色 `--rl-fg-subtle` 在 `--rl-bg-subtle` 上 4.29:1（导航编号、代码标题）→ 调整 `fg-muted`/`fg-subtle`，并把这些组合加入对比度测试。
5. 320px Foundations 色板网格 `minmax(280px)` 超出 1px → `minmax(min(100%, 280px), 1fr)`。
6. 抽屉关闭时菜单按钮仍在 `inert` 区域内，焦点归还失败 → 在提交后的 effect 中归还焦点。
7. 视觉审查：暗色下程序聚焦的 H1 出现焦点框 → 非操作型标题不显示焦点环；Surface/Motion 卡片空白、1920 宽屏右侧大面积留白 → 补充真实控件/规范内容，宽屏内容上限 1600px。
