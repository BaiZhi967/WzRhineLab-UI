## 1. 退出门禁
ROADMAP M4 的核心产物是「原创扫描 / 轨道 / 解密模式、动效播放器、reduce 对照、可选 3D」，退出门禁为「不影响基础包体；性能 / 减动 / 中断验收」。

| 门禁项 | 状态 | 证据 |
| --- | --- | --- |
| 原创扫描 / 轨道 / 解密 | ✅ | ScanSurface、OrbitalDiagram、ArchiveReveal（`packages/effects`） |
| 动效播放器 + reduce 对照 | ✅ | MotionPlayer：Default / Slow ×0.25 / Reduced / Interrupt 四通道（MOTION.md 要求） |
| 可选 3D | ⏸ 未实现 | 有意延后：没有对应的设计规范与性能预算；ADR-0004 给出了以后的接入方式 |
| 不影响基础包体 | ✅ | 见第 3 节：Button + Text 仍为 2.5 kB gzip，基础包整包中不含任何 effects 代码；包边界测试强制单向依赖 |
| 减动 | ✅ | 单测：减动时直接切换、无中间帧；E2E：Reduced 通道立即完成；减动扫描为静态描边（`animation: none` + inset 描边）；轨道不旋转；每个 keyframes 都有减动覆盖（测试强制） |
| 中断 | ✅ | 单测：解密进行到一半反向时从当前进度回退；E2E：Interrupt 通道反向后最终回到隐藏态 |
| 性能 | ⚠️ 部分 | 生命周期已验证：页面隐藏时暂停（E2E）、完成后停止 rAF（单测）、卸载时清理（单测）、离开视口停止旋转（实现，未单测）。**未做**：CPU 降速、30fps、长时间帧耗时 profiling |

## 4. 视觉审查
- 首轮：播放器四个通道在 1280px 下排成 3 + 1，Interrupt 单独占一行；整页截图里吸顶栏被画在页面中间（截图前没有滚回顶部）；移动端设置组边框内留白；390px 下轨道图例被压成一字一行。
- 第二轮：通道改为容器查询下的 4 → 2 → 1 列；截图前滚回顶部；移动端设置组的选项铺满边框；图例换到图形下方。但图例换行的阈值过于激进，1280px 下也换了行，导致相邻卡片高度失衡。
- 第三轮：轨道外包一层容器，只在自身宽度小于 400px 时换行。复审全部通过。
