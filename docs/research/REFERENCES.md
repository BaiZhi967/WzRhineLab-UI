## 技术与标准
- [Motion for React 安装](https://motion.dev/docs/react-installation)：npm `motion`，入口 `motion/react`。
- [Motion Reduced Motion](https://motion.dev/docs/react-accessibility) 与 [MotionConfig](https://motion.dev/docs/react-motion-config)。
- [Base UI](https://base-ui.com/react/overview/about) / [React Aria Components](https://react-spectrum.adobe.com/react-aria/index.html) / [Radix Primitives](https://www.radix-ui.com/primitives/docs/overview/introduction)：复杂交互候选，一次只选择一个。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：语义、对比、焦点、目标尺寸与运动等门槛。
