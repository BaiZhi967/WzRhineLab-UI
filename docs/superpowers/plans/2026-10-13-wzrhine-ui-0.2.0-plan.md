# WzRhineLab-UI 0.2.0 Wpi 接入补齐计划

## 目标与边界

在不修改 `Wpi-Agent` 的前提下，补齐需求清单 B0–B9 中的全部 P0/P1 能力，并将已确认的三处一次性 effects 需求接入 `@wzrhine/effects`。范围覆盖 `@wzrhine/react`、`@wzrhine/agent-core`、`@wzrhine/agent` 和 `@wzrhine/effects`；P2 项留待 0.2.x。实现遵循现有 `rl-*` token、`motion/react`、reduced-motion、Base UI 和公共入口约束。

## 批次与实现顺序

1. **B0**：重新安装依赖，确认 motion 14.1.0；建立 0.2.0 版本与升级文档基线。
2. **B1**：补齐公共图标入口，统一 24px 网格和 SVG 描边契约。
3. **B2**：扩展 agent-core 材料契约（`xhigh`、文件材料分页/统计、patch 基线）以及 Composer 附件发送和 ModelPicker effort 状态；为工具详情补齐这些字段的渲染。
4. **B3–B4**：在 react 中下沉 `ResizeHandle`，实现 `Workbench`、`NavRail`、`NavList`、`CountBadge`、`Tree` 及选中指示动效。
5. **B5**：补齐 Popover 锚点能力、Tag、AlertDialog/Dialog/RadioGroup 扩展，并实现 SkillPicker、ReferencePicker、草稿重试、slash 触发和权限回执。
6. **B6**：修复消息嵌套滚动、历史锚点、追尾保护和复制失败持久提示；实现 `RunOverview`、会话分组和 ContextUsage 估算/打开状态；加入 AgentShell 下钻和附件入场动效。
7. **B7**：扩展 manage-files、原生模型、工具失败、问卷单选推进、终端/子 Agent 列表和对应 loading/error/retry 状态。
8. **B8**：补齐其余覆盖层/表单 P1 API。
9. **B9**：实现 `OrbitalDiagram`、`ScanSurface`、`ArchiveReveal` 的尺寸、节点状态、时长、原生属性、可见性暂停和副作用开关。

每个批次先新增最小行为测试并确认测试因缺失能力失败，再实现最小代码，最后运行该包测试、类型检查与构建。测试优先验证公开行为、键盘/焦点、错误和 reduced-motion；不依赖私有 class 或实现细节。

## 公共接口约束

- 新 API 从对应包根入口导出，并在 API 类型测试中锁定闭合联合类型。
- 组件只接收 view-model/公开 props，不依赖 Wpi DTO、运行时、传输或 SDK。
- 动效统一通过现有 motion 生命周期和 provider 上下文；暂停、卸载、中断、隐藏页和 reduced-motion 都必须有测试。
- 样式只引用 `--rl-*` token，新增类名使用包既有 `rl-*` 前缀。

## 终验

完成全部批次后运行：

```text
pnpm install
pnpm typecheck
pnpm test
pnpm build:packages
pnpm verify:packages
pnpm release:check
```

检查 `git diff` 确认只包含 `WzRhineLab-UI`，并记录尚未能在本环境完成的浏览器/人工验收证据。
