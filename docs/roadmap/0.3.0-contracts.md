# WzUI 0.3.0 公共合同：API 草案、状态、焦点与测试矩阵

> 2026-10-15；任务 P030-00；基于 0.2.0 源码基线 `c6b2af6`。本文冻结 0.3.0 的状态所有权、布局／焦点／滚动合同与公开 API 草案，供 P030-01 起的实现任务遵循。包决策与九候选裁决见 [ADR-0014](../development/adr/0014-patterns-package-and-p030-scope.md)。所有签名均为草案：实现时可在不违反合同语义的前提下细化，最终以 API report 为准。

## 1. 范围

- 公共组件八个：ListDetail、InspectorPanel、QueryToolbar、AppliedFilters、ViewSwitcher、SelectionToolbar、ResourceGrid、SectionIndex，全部进入拟建的 `@wzrhine/patterns`。
- Recipe 三个：集合页、记录详情页（承载 RecordDetail 降级后的组合责任）、分组设置页。
- 参考应用：archive-desk 扩展（P030-08，合同另附于实现任务）。

## 2. 依赖闭包

```text
@wzrhine/tokens   ←  @wzrhine/react  ←  @wzrhine/patterns
                                       ←  @wzrhine/effects / agent-core / agent（与 patterns 互不依赖）
```

- patterns `dependencies`：`@wzrhine/tokens`（`workspace:*`）；`peerDependencies`：`@wzrhine/react`（`workspace:^`，随 effects／agent 惯例，保证 RhineProvider 上下文同一性）、`react` / `react-dom`（`^19.0.0`）、`motion`（`^14.0.0`）。
- patterns 复用 react 的 `RhineProvider`（主题／密度／动效／portal）与既有组件（Button、Surface、Skeleton、Alert、EmptyState、MetadataList、Drawer 等），不新建主题体系、不新增焦点陷阱。
- 文案：独立 `PatternsMessagesProvider` + `zhCN` / `enUS` 表 + 组件属性覆盖，机制对齐 ADR-0009，键位不并入 react 的 `RhineMessages`（见 ADR-0014 §3）。
- 样式：`rl-` 前缀类名 + `--rl-*` tokens；`@wzrhine/patterns/styles.css` 显式导入，入口无 CSS 副作用。

## 3. 状态所有权合同

| 状态 | 所有者 | patterns 层职责 |
| --- | --- | --- |
| 查询值（已提交）、筛选项、排序、页码 | 调用者 | 受控值 + 变更回调；查询变更后的页码重置由调用者处理 |
| 视图模式（列表／网格） | 调用者 | ViewSwitcher 受控值；切换不重置查询、选择、页码 |
| selectedIds（有限 ID 集） | 调用者 | 忠实呈现数量与范围；清空与批量执行由调用者发起 |
| 当前详情 ID | 调用者 | ListDetail 受控开关；快速切换时取消过期焦点任务与观察 |
| loading / error / 执行结果 | 调用者 | 按事实呈现（骨架、错误、重试、busy 禁用），不推断成功 |
| 输入中的搜索文本（未提交） | QueryToolbar 内部（可受控接管） | 提交前不触发 `onQueryChange`；IME 组合期间不提交 |
| ListDetail 宽窄模式（auto 时） | 组件（容器测量） | `onModeResolve` 可观察；显式 `mode` 时为受控 |
| SectionIndex 当前章节 | 组件观察（可受控接管） | 被动高亮不抢焦点；主动导航与被动观察分离 |
| hover、局部展开、焦点记录 | 组件 | 不越过公开可控边界 |
| 数据缓存、请求取消、去重、localStorage | 宿主 / 参考 adapter | 不绑定 Query／Store，不读写存储 |

通用规则：

- 稳定 ID 是数据身份；禁止数组下标作 key 或选择标识。
- 组件发出的是操作意图；`loading` / `error` / 结果由调用者回传后再更新呈现。
- 同一状态不得同时被组件内部与调用者写入；非受控 `default*` 仅限明确的局部初值。

## 4. 布局、焦点与滚动合同

### 4.1 ListDetail 嵌入语义

- 不渲染 `nav`、不渲染第二个 `main`；同页多实例的状态、文案、测量互不干扰（测量基于自身容器，不读全局窗口宽度）。
- SSR／首帧：`mode="auto"` 时初始渲染恒为 `split` 结构（确定值），挂载后经容器测量切换 `overlay`；初始 render 结构一致，不存在水合不一致。显式 `mode` 不做测量。
- 宽布局两区并置；窄布局详情替换列表视图并提供明确返回入口。
- 打开详情：焦点按约定进入详情标题或明确入口；关闭详情：优先回到打开它的控件；控件已被过滤或删除时回到稳定集合入口（列表标题或工具区）。
- 快速切换记录必须取消过期的焦点任务（沿用 react 包 `useLatestGuard` 一类机制），不跳到旧记录。
- 滚动位置：列表区滚动位置在详情开关往返后保持（除非调用者变更查询）。

### 4.2 焦点落位规则

- AppliedFilters 移除单项后：焦点落到相邻项的移除按钮；移除最后一项后落到清空入口或工具区稳定入口。
- Pagination 已有先例延续：busy 期间控件保持可聚焦（`aria-disabled`），焦点不掉到 `body`。
- InspectorPanel 隐藏（`open=false` 或卸载）后不残留可聚焦控件；退出动效期间可见性由动效层控制，结束时清理。
- 批量操作执行中：按钮禁用防重复提交，焦点保持在工具区。

### 4.3 滚动合同

- 每个滚动区域声明所有者：ListDetail 的列表区、详情区各自滚动；SectionIndex 必须显式 `scrollRoot`（默认最近滚动祖先），并支持固定标题 `offsetTop`。
- SectionIndex 内容高度变化时重新观察；卸载清理全部观察器，不继续更新状态。
- 减动偏好下不平滑滚动；无 JS 时 SectionIndex 渲染为普通锚点链接。

### 4.4 IME 合同

- QueryToolbar 搜索输入在 `compositionstart` 至 `compositionend` 期间，Enter 不触发提交；组合结束后提交语义恢复。
- 提交时机为明确行为（Enter／提交按钮／清空），不做输入即查的隐式提交；调用者可另行实现防抖，组件不内置。

## 5. 选择范围语义

- 首版仅支持显式有限 ID 集合（`ReadonlySet<string>`，与 DataTable 现有契约一致）。
- 范围三分且必须可解释：**当前页**（当前分页可见）、**已加载**（客户端持有的数据）、**全部查询结果**（含未加载）。SelectionToolbar 通过 `scope` + `totalLabel` 呈现，不显示未经实现的「全部结果已选择」。
- 过滤后保留的隐藏选择不静默丢失；界面显示总选择数与当前可见范围；清除策略由调用者决定。
- 删除或替换数据导致的失效 ID 由调用者（adapter）清理；组件不擅自推断数据是否已删除。

### 6.1 ListDetail（`src/layout/ListDetail.tsx`）

```ts
type ListDetailMode = 'split' | 'overlay';

type ListDetailProps = {
  /** 集合区内容：DataTable、ResourceGrid 或自定义列表。 */

  className?: string;
```

## 7. Recipes（P030-07 实现定位）

| Recipe | 承担内容 | 状态槽标准 |
| --- | --- | --- |
| 集合页 | QueryToolbar + AppliedFilters + ViewSwitcher +（DataTable 或 ResourceGrid）+ SelectionToolbar + Pagination 的完整组合；演示查询变更重置页码 | 首载骨架、空、无结果（EmptyState kind 区分）、错误重试 |
| 记录详情页 | **RecordDetail 降级后的组合标准**：RecordHeader + MetadataList + SectionIndex + 分区容器；loading 用 Skeleton + `aria-busy`；错误用 Alert + 重试；详情 ID 切换时旧内容与新请求的视觉区分方式 | 调用者持有 detailId 与异步事实 |
| 分组设置页 | 现有 Form / Fieldset 组合 + dirty／saving／saved／error 状态与离开确认；保存由 adapter 执行 | 失败重试不丢输入 |

每个 recipe 必须说明：用途、数据适配点（命名 adapter）、状态所有者、响应式行为、键盘路径、错误与取消、不适用场景。位置由 P030-01 确定（唯一示例位置，不复制组件库实现）。

## 9. 逐组件测试矩阵

### 9.1 组件级

| 组件 | 必须覆盖 |
| --- | --- |
| ListDetail | 键盘打开／关闭；窄宽切换（容器阈值）；触发控件移除后的 fallback；详情加载失败呈现；快速切换取消过期焦点；两个同页实例互不污染；列表滚动位置保持；SSR 初始结构一致 |
| InspectorPanel | 可访问名称；open=false 无可聚焦残留；长路径／长属性换行；未知类型与空数据表现；禁用与执行中操作 |

| SectionIndex | 重复标题不同 ID；长目录；隐藏章节；动态内容重观察；快速切换详情；浏览器返回；减动不平滑滚动；卸载后不更新状态；无 JS 锚点可用 |

### 9.2 场景级（archive-desk 承载，P030-08）

对应 [0.3.0 计划 §9](0.3.0-plan.md) 的十二个场景：首次加载、刷新区分旧结果与 busy、无记录与无结果区分、请求失败不丢查询与选择、部分图片失败单项降级、选择后筛选或分页的可解释性、批量取消／失败可恢复、详情快速切换不串台、关闭详情焦点回收、中文输入不误提交、双实例隔离、SSR／无 JS 首屏。
