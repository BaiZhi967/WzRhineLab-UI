# WZUI-REQ-20261016-001 · Markdown 内容层

## 1. 请求状态

- 请求编号：WZUI-REQ-20261016-001
- 请求名称：建立安全、可复用的 Markdown 内容阅读层
- 权威记录位置：本文件；总体设计见 [Markdown 内容层、编辑器层与写作工作台设计方案](../../superpowers/specs/2026-10-16-markdown-writing-workbench-design.md)
- 来源：维护者场景 / 写作工作台
- 分类：ArchitectureStudy / NewComponent
- 优先级：P2；当前可通过宿主 renderer 临时实现，但无法形成统一内容合同
- 库侧状态：Triaged
- 消费状态：NotApplicable
- 目标版本：R2 / 0.4.x 候选；尚未排期

## 2. 真实场景

- 用户目的：在 WzRhineLab-UI 中统一展示 Markdown 文章、笔记、代码、引用、图片和附件。
- 期望表现：同一份内容可以用于独立阅读页、侧栏预览和 Agent 领域预览，长中文、代码块和图片失败不破坏布局。
- 当前替代：由调用方自行接入 Markdown parser、代码高亮和链接策略，行为与样式无法统一。
- 影响范围：内容阅读、预览、写作工作台和未来的产物展示。

## 3. 归属判断

- 类型：可选领域前端 / 内容基础层
- 目标 package：候选 `@wzrhine/content`
- 现有公共 API：`SectionIndex`、`ScrollArea`、`Tabs`、`CodeBlock` 可部分组合，但缺少 Markdown 解析、安全和标题索引合同。
- 必须进入库：Markdown renderer 合同、标题抽取、代码块行为、链接/图片安全策略、内容状态 fallback。
- 留在宿主：文件读取、URL 授权、附件下载、远程请求和内容业务模型。
- 需要先做：安全策略、parser/highlighter 许可证和可选依赖评估。

## 4. 最小支持范围

### 本次必须支持

- [ ] `MarkdownRenderer` 受控接收 `source`，不自行读取文件。
- [ ] 标题、段落、列表、引用、表格、代码围栏、链接和图片的语义渲染。
- [ ] `HeadingIndex` 生成稳定 slug 与章节数据，能接入 `SectionIndex`。
- [ ] 原始 HTML 默认关闭；不支持协议显示可解释 fallback。
- [ ] 代码块支持复制、横向滚动和可选 renderer。
- [ ] loading、empty、error、图片失败和未知扩展状态可呈现。

### 本次明确延后

- [ ] PDF、Office、音视频和 Mermaid 等重型格式。
- [ ] 协同编辑、评论、反向链接数据库和全文索引。
- [ ] 默认内置某个高亮引擎或远程资源服务。

### 状态矩阵

| 状态 | 视觉结果 | 语义／焦点结果 | 数据所有者 |
| --- | --- | --- | --- |
| ready | 正常语义内容 | 标题、链接和图片可访问 | 调用者提供 source |
| loading | 骨架或稳定占位 | `aria-busy`，不把占位当正文 | 调用者 |
| empty | 明确空内容提示 | 说明没有可读内容 | 调用者 |
| error | 错误提示和重试入口 | 保留错误名称与可操作重试 | 调用者 |
| unsupported | 类型和原因 fallback | 不静默丢失内容 | renderer / 调用者 |

## 5. API 和依赖

- 唯一事实源：`source: string`；派生标题和统计不可反向覆盖 source。
- 公开入口：候选 `@wzrhine/content` 与 `@wzrhine/content/styles.css`。
- parser、sanitize、highlight 作为可选依赖或 renderer 注入，不进入 `@wzrhine/react`。
- 链接、图片和附件通过 resolver/callback 注入；不直接访问文件系统。
- SSR 不读取浏览器 API；对象 URL、Worker 和观察器由创建者释放。
- 若从 `@wzrhine/agent` 抽取 `CodeBlock`，保留兼容导出并记录迁移说明。

## 6. 交互、无障碍和动效

- 标题使用真实 heading 层级；代码块使用 `figure/figcaption/pre/code`。
- 代码滚动区可聚焦，复制状态使用短暂 polite 状态播报。
- 链接、图片和错误操作具有明确名称；不以颜色作为唯一状态。
- 内容进入和图片加载不使用不可中断的大幅动画；reduced-motion 下保持静态。
- 验证 320/390/768/1280/1920、中文长文、英文长词、长代码和 200% 缩放。
