## 2. 场景与复现

三个等宽卡片由 CSS Grid 排列，下方 SVG 使用固定 600×170 坐标与固定 100/300/500 端点。当容器变化，SVG 的等比居中与 CSS gap 不一致，线条不再连接卡片底边中点。已有只检测横向溢出的研究检查没有捕捉这个缺陷。

期望：连线始终来自真实端点；窗口、独立容器、字体换行、节点增删与滚动均不依赖魔数修补。后续标注、路径动画和仪器视觉共用几何与生命周期基础。

## 5. 所有权与状态

宿主拥有 active、业务状态、内容和节点；库只测量局部几何并渲染装饰。稳定 ID 区分端点，ref 为 null 隐藏相关路径；未测量／SSR 不画猜测坐标。语义内容独立于效果，CSS/SVG 装饰不拦截指针，减动直接显示目标。

既有 Provider、Motion 配置与生命周期为唯一来源。新时间插值只由 motion/react 承担，单帧测量调度不得变成默认永久渲染循环。

## 6. 验收条件

1. getScreenCTM 映射后的路径端点与卡片指定边中点偏差 ≤1 CSS px。
2. 五宽度、容器独立缩放、不等宽卡片、多行文本、滚动、多实例、端点替换与移除。
3. 反向／取消／隐藏／卸载清理，无默认空闲帧循环；减动与慢放不相互覆盖。
4. 现有语义与焦点合同不因延迟退出而破坏；装饰图形不作为业务结果来源。
5. SSR 确定初始态、公开入口与独立样式、可裁剪、没有重依赖进入基础包。
6. 新增实际文档、API 与检查结果；五宽度截图逐项说明与旧页面差异，不全量刷新无关基线。
