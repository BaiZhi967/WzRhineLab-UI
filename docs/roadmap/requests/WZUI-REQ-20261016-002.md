# WZUI-REQ-20261016-002 · Markdown 编辑器层

## 1. 请求状态

- 请求编号：WZUI-REQ-20261016-002
- 请求名称：建立可替换内核的 Markdown 编辑器层
- 权威记录位置：本文件；总体设计见 [Markdown 内容层、编辑器层与写作工作台设计方案](../../superpowers/specs/2026-10-16-markdown-writing-workbench-design.md)
- 来源：维护者场景 / 写作工作台
- 分类：ArchitectureStudy / NewComponent
- 优先级：P2；当前没有公共编辑器合同，但首期可先使用宿主局部实现
- 库侧状态：Triaged
- 消费状态：NotApplicable
- 目标版本：R4 / 0.6.x 候选；尚未排期

## 2. 真实场景

- 用户目的：编辑 Markdown 文档，切换源码、预览和双栏模式，并能明确看到保存状态。
- 期望表现：中文 IME、光标、选区、撤销重做、粘贴、只读、保存失败和冲突状态可恢复。
- 当前替代：`Textarea` 或宿主自带编辑器；缺少统一 toolbar、tab、保存和焦点合同。
- 数据形态：单文档长文本、多文档标签、可选 revision、可选附件引用。

## 3. 归属判断

- 类型：可选编辑器领域层
- 目标 package：候选 `@wzrhine/editor`
- 现有公共 API：`Textarea`、`Tabs`、`IconButton.pressed`、`CommandPalette` 可组合，但不能承担长文编辑内核和文档标签行为。
- 必须进入库：`EditorHost`、`EditorSurface`、`DocumentTabs`、`EditorToolbar`、`SaveStatus`、`EditorModeSwitcher`。
- 留在宿主：文件读写、自动保存、防抖、冲突处理、命令注册、路由和权限。
- 需要先做：编辑器内核、许可证、bundle、SSR、IME 和性能实验。

## 4. 最小支持范围

### 本次必须支持

- [ ] Markdown 原文作为唯一事实源。
- [ ] source、preview、split 三种受控模式。
- [ ] `EditorHost` 以 value/selection/actions 形式连接编辑器内核。
- [ ] `DocumentTabs` 支持当前文档、关闭、未保存标记和焦点恢复。
- [ ] `EditorToolbar` 支持格式命令、撤销/重做、模式切换和插槽。
- [ ] `SaveStatus` 支持 clean、dirty、saving、saved、error、conflict。

### 本次明确延后

- [ ] 完全 WYSIWYM、实时协同和远程光标。
- [ ] 块拖拽、块菜单、图谱、反向链接和标签数据库。
- [ ] 自动把输入变化标记为保存成功。
- [ ] 在 `@wzrhine/react` 中直接引入编辑器内核。

### 状态矩阵

| 状态 | 视觉结果 | 语义／焦点结果 | 数据所有者 |
| --- | --- | --- | --- |
| clean | 无提示或稳定状态标记 | 编辑区可继续操作 | 调用者回传 |
| dirty | 未保存标记 | 不阻断编辑；关闭时可触发保护 | 调用者 |
| saving | 状态标记和轻量 busy | 编辑区保留焦点，避免重复保存 | 调用者 |
| saved | 短暂确认 | 使用 polite 状态播报 | 调用者 |
| error | 错误和重试 | 原文、选区和焦点保留 | 调用者 |
| conflict | 冲突提示和处理入口 | 不覆盖本地编辑内容 | 调用者 |

## 5. API 和依赖

- `EditorHost` 不暴露具体内核的 state 类型。
- 受控值：`source`、`mode`、`readOnly`、`saveStatus`、`selection`。
- 操作：`onChange`、`onSelectionChange`、`onSave`、`onModeChange`、`onInsertAsset`、`onOpenLink`。
- 文档 ID 和 revision 必须稳定；禁止使用数组下标作 identity。
- 编辑器内核采用可选 adapter，动态加载，不进入基础 React 包。
- SSR 输出只读内容或稳定 fallback，客户端再挂载编辑器。

## 6. 交互、无障碍和动效

- IME 组合期间 Enter、Backspace、快捷键和 picker 操作不误触发。
- 工具栏具备 `role="toolbar"`、可见焦点、方向键和明确的 toggle 语义。
- 关闭标签后焦点回到相邻标签或触发元素；关闭保护使用现有 `AlertDialog`。
- 保存状态不通过持续动画表达；reduced-motion 下保持可读静态状态。
- 窄屏把文件树和目录折叠为 Drawer/Popover，编辑区保持可操作。
- 验证 320/390/768/1280/1920、长中文、长路径、长代码、中文输入和 200% 缩放。

## 7. 验收条件

- [ ] 多文档切换、关闭、未保存保护、错误重试和冲突保留原文。
- [ ] SSR、卸载、快速切换和旧异步结果覆盖防护有证据。
- [ ] 包体、lazy chunk、API、文档、许可证和真实安装有证据。
- [ ] 首个可运行参考场景完成 source/preview/split 闭环。

## 8. 主线插入与恢复

- 处理方式：R4 候选 / ArchitectureStudy 先行。
- 必要依赖：内容层合同、`Toolbar` / `ToggleButton` 基础交互、现有 `Tabs` / `AlertDialog`。
- 禁止扩张：不把文件系统、保存服务、命令总线和协同后端加入编辑器包。
- 回滚条件：内核在 IME、SSR、包体或数据往返方面不可接受时，保留 source-only 适配器。
