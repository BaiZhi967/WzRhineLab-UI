# WzUI 0.3.0：应用级页面与集合浏览

> 2026-10-14；状态 Planned；基于 0.2.0。本文定义下一工作包，不表示下列组件或新包已经存在。目标是独立交付，不以任何消费项目接入完成为前置。

## 1. 版本目标

完成一条真实交互链：搜索与筛选 → 查看集合 → 切换列表／网格 → 选择记录 → 批量操作 → 打开详情 → 章节定位 → 返回集合。

同时产出能够被不同 React 页面使用的公共模式、recipes、公开文档和库内验收应用。成功标准不是组件总数，而是同一套合同能支撑档案与资源两类不同数据形态，且不需要业务 CSS 补丁、私有 imports 或指定后端。

## 2. 当前能力与增量边界

| 已有能力 | 本版如何复用 | 禁止的重复建设 |
| --- | --- | --- |
| Workbench／导航／ResizeHandle | 提供外壳与已发布尺寸／索引能力 | 再造一个相同职责的 AppShell |
| DataTable／Pagination | 受控排序、分页、行选择、状态与表格呈现 | 重写完整表格引擎 |
| Tree／Input／Combobox／Tag | 组合分类、搜索和条件控件 | 自建第二套基础交互底座 |
| Drawer／Dialog／Popover | 必要的详情覆盖层与操作 | 手写焦点陷阱或独立 Portal 体系 |

| EmptyState／Alert／Skeleton／Toast | 呈现结果与反馈 | 每个页面各造一套状态样式 |

## 3. 范围冻结

本版范围为：ListDetail、InspectorPanel、QueryToolbar、AppliedFilters、ViewSwitcher、SelectionToolbar、ResourceGrid、RecordDetail、SectionIndex，以及集合页／详情页／设置页 recipes 和 archive-desk 扩展。

P030-00 允许基于复用分析将纯排版候选降为 recipe，须记录原因、替代方式与验收位置；不得通过删除实际交互能力虚假缩小验收。最终导出清单在该任务确认。

不包含完整编辑器、PDF 引擎、节点流程图、复杂图表、服务端查询、通用上传后端、无限滚动、虚拟化、服务端全结果选择、拖拽排序或业务权限执行。

新包 `@wzrhine/patterns` 是候选方案。若选用，必须完整接入构建、公开导出、显式样式、API report、安装、size 与许可证检查；不得只创建目录。具体决策见 [架构](architecture.md)。

## 4. 公共状态合同

查询值、筛选项、排序、页码、视图模式、selectedIds、详情 ID、异步状态由调用者持有。公共组件提供值和变更回调，不直接发起请求，不默认读写 localStorage，不绑定路由器或全局 Store。

单一来源原则：同一个状态不能既被模式组件隐式维护，又由 DataTable 或参考应用 adapter 独立维护。非受控模式仅用于明确的局部展开，必须与受控模式分别测试。

稳定 ID 是数据身份，不使用数组下标。组件发出操作意图不代表操作成功；调用者回传 loading／ready／error 等事实后再更新结果展示。

过滤后保留的隐藏选择、当前页选择和总选择必须可解释。删除或替换数据导致的失效 ID 由调用者清理，UI 不擅自推断数据是否已删除。

## 5. 页面组织组件

### ListDetail

提供集合与详情的组合、受控开关、当前记录 ID、返回入口和布局模式。宽布局两区并置；窄布局采用详情替换视图，保留明确返回路径。首版不默认启用拖拽布局和复杂窗口停靠。

布局应由可用容器空间决定，不只依赖全局窗口宽度；同页嵌入多个实例时互不干扰。SSR 使用确定的初始模式，客户端测量后调整，不能产生水合结构不一致。

打开详情后按约定定位到详情标题或明确入口；关闭后优先回到原触发控件，已被过滤或删除时回到稳定集合入口。快速切换记录必须取消过期焦点任务。内嵌模式不创建重复 main landmark。

最少测试：键盘打开／关闭、窄宽切换、触发控件移除、详情加载失败、快速切换、两个实例、滚动位置保持。

### InspectorPanel

提供标题、关闭、元数据、操作和内容槽位，具有可访问名称。它是区域组件，不自行执行业务动作；需要覆盖层时由 recipe 组合现有 Drawer。

长属性、路径、未知类型、无数据、禁用操作和执行中状态都应有明确表现。隐藏面板不得保留可聚焦的不可见控件。

### 页面与设置 recipes

提供标准组合示例：页头与操作区、筛选工具区、结果与分页、列表详情，以及分组设置表单。设置 recipe 使用现有表单能力表现 dirty／saving／saved／error 和离开确认；保存由 adapter 执行。

recipes 是消费起点，不是新运行时。不固定业务路由和存储接口，不复制基础组件源码。需要宿主实现的部分以命名明确的 adapter 标出。

## 6. 集合浏览组件

### QueryToolbar 与 AppliedFilters

QueryToolbar 负责布局、控件分组、结果摘要和 reset 操作，不提供自己的筛选 DSL。搜索输入区分正在输入的值与已提交查询；参考应用采用明确提交行为，中文组合输入期间 Enter 不误提交。

AppliedFilters 使用稳定条件 ID、可读名称和值、单项移除与全部清空动作。长条件可换行；移除条件后焦点落到合理相邻位置或清空入口。没有筛选结果与没有任何记录分别呈现。

测试覆盖中文组合输入、重复条件标签、长标签、清空最后一项、加载中操作策略与错误重试。查询变更后的页码重置由 adapter 处理，并在 recipe 中演示。

### ViewSwitcher

只控制允许的视图选项及当前值，使用已有合适的单选语义。切换列表／网格保持查询、选择与详情身份；不重新发起请求或自动重置页码。

缺失或不再支持的选项由调用者处理并提供 fallback。可访问名称、当前状态和禁用状态明确；不让图标成为唯一标签。

### SelectionToolbar

展示已选数量、当前范围、清空选择和批量动作。批量操作由调用者执行；执行中不能重复提交同一操作，失败时保持可恢复选择。

首版支持显式有限 ID 集合。必须区分当前页、已加载数据和全部查询结果，不显示未经实现的“全部结果已选择”。超过本地能力的选择需求重新立项。

### ResourceGrid

提供资源卡片布局、稳定 key、受控选择、打开入口、缩略图和状态槽位。默认列表语义加可命名的 checkbox／链接或按钮，不自行实现复杂 ARIA grid 导航。

打开、选择与更多操作分别可触达，避免嵌套交互控件。图像有保留尺寸、加载与失败占位；无缩略图也可操作。资源地址由调用者提供并授权，组件不读取文件系统。

切换数据、卸载或更换图片时不遗留观察器和对象 URL；资源释放由真正创建资源的一方负责。测试多种宽高比、超长标题、重复名称、空网格、失败图片与键盘操作。

## 7. 记录详情组件

### RecordDetail

组合标题、记录状态、元数据、正文、操作与分区。不强迫消费项目使用统一的数据库 schema；通过 children／slots／render props 接收内容。

既有 RecordHeader 和 MetadataList 作为基础使用；不得改变已发布组件的默认语义。没有真实编号、时间或权限时不补造档案字段。

详情 ID 改变时，加载、错误与旧数据由调用者明确控制；UI 不把旧记录内容伪装成新记录结果。

### SectionIndex

提供明确的 section ID、名称、当前章节和定位操作。支持显式滚动根、固定标题偏移以及内容高度变化；无 JS 时基本锚点仍可用。

点击后应正确更新位置；滚动观察更新当前章节但不持续抢夺焦点。用户主动导航与被动观察分开。减少动态时不平滑滚动；清理观察器，卸载后不继续更新状态。

测试重复标题但不同 ID、长目录、隐藏章节、动态内容、详情快速切换与浏览器返回。ID 生成策略必须稳定，不能依赖随机数。

## 8. 独立参考应用

扩展现有 [archive-desk](../../examples/archive-desk)，继续只使用公开入口。提供两个不同记录模型的页面，共用模式组件，不让数据模型倒灌进基础包。

档案页：本地创建／编辑元数据、搜索、分类筛选、受控排序与分页、选择、删除确认、详情章节。资源页：列表／网格切换、类别条件、缩略图、选择、属性面板与预览槽位。设置页作为 recipe 展示保存失败与重试，不承担新设置后端。

示例 adapter 执行实际本地操作，提供可重复的加载、失败、空结果和过期响应注入；localStorage 有命名空间、版本和重置入口。不含鉴权的示例仅监听本地，不作为公网服务部署。

建议测试数据集为 1,000 条档案和 240 条资源，按明确分页范围呈现。这是拟定验收输入，不是已有性能成绩或容量承诺。不得用堆积全量 DOM 的演示推断性能合格。

## 9. 状态与场景矩阵

| 场景 | 必须验证的结果 |
| --- | --- |
| 首次加载 | 可解释等待态，布局不剧烈跳动，无可误操作的伪记录 |
| 已有结果刷新 | 旧结果与 busy 明确区分，动作策略一致 |
| 无记录／无搜索结果 | 两类文案和动作不同，清空条件能恢复 |
| 请求失败 | 错误与重试可触达，不丢失查询和选择 |
| 部分图片失败 | 单项降级，不阻塞整个集合 |
| 选择后筛选或分页 | 隐藏选择和当前范围可解释，不静默操作未知记录 |
| 批量操作取消／失败 | 不清空用户意图，可再次执行且无重复提交 |
| 详情快速切换 | 过时内容、焦点和异步结果不覆盖当前项 |
| 关闭详情 | 原入口或稳定 fallback 获得焦点 |
| 中文输入与长内容 | 不误提交，文字和工具区不溢出 |
| 两个同页实例 | 焦点、条件、选中和面板状态互不污染 |
| SSR／无 JS | 首屏确定、内容可读，不访问不存在的浏览器对象 |

## 11. 版本退出条件

所有 Must 范围有实现、文档、状态矩阵和测试；或经维护者明确批准降为 recipe 并保留对应交互。未执行门禁不能标为 Accepted。

库侧回归、五宽度、键盘、中文输入、主题／密度、减动、SSR、样式隔离、真实打包安装和 API 检查满足 [质量与发布](quality-and-release.md)。新增模块有空载／典型／压力场景的包体和交互基准，不能只凭截图验收。

archive-desk 中两类数据形态完成操作闭环；公开示例不需要私有路径和源码 alias；当前 0.2.0 导出与行为的回归有证据；新增包若存在则进入全部相关门禁。

发行记录包含实际版本、commit、环境、测试日志、未覆盖项、升级与回滚。消费项目是否已安装单独记录，不阻断已满足库侧门禁的版本发布。

## 12. 风险与降级策略

| 风险 | 处理 |
| --- | --- |
| 模式组件只有外观包装 | 降为 recipe，减少公共 API，但保留场景交付 |
| ListDetail 与现有外壳重叠 | 明确内嵌边界，不添加第二个全局外壳 |
| 新包扩大构建改造 | P030-00 决策，完整门禁后才对外导出 |
| 集合状态互相覆盖 | 单一状态源、受控合同与跨视图测试 |
| 需求中途增加 | 走版本范围变更，记录被替换任务和恢复点 |
| 高级网格或资源预览过重 | 保持首版列表语义／预览槽位，另行立项重能力 |
| 环境缺失 | 精确记录未执行项；缩小未声明范围，不伪造验收 |

## 13. 本轮不做的变更

不重画已批准图标，不更换视觉语言或 Motion 底座，不重构现有领域包，不绑定消费项目 DTO，不升级全仓依赖，不创建公共平台生态，不触发未经授权的 Actions。

规划 PR 仅更新文档；组件实现、版本变更和 npm 发布属于之后的独立实施工作包。
